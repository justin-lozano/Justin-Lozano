# Agent Instructions

This repository is a portfolio scaffold. Conventions to follow when working here:

- `capabilities/` holds one folder per capability; each capability folder contains `README.md`, `spec.md`, and the model file.
- `docs/briefs/` holds documents written **before** work begins; `docs/decisions/` holds recommendations written **after** work is complete.
- Do not create folders named after a course, a semester, or a week.
- Do not write bio or resume content on Justin's behalf — `RESUME.md` and any bio content are his to write.
